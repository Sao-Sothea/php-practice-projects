# PHP Bank Withdrawal – Exception Handling

## Description

A simple PHP project demonstrating exception handling through a bank withdrawal simulation.

## Concepts Covered

- PHP Functions
- Type Declarations
- Throwing Exceptions
- Try-Catch-Finally
- Input Validation

## Features

- Validate withdrawal amounts.
- Check available account balance.
- Prevent withdrawals exceeding the available balance.
- Handle errors using PHP exceptions.
- Display the remaining balance after a successful transaction.

## Example

Initial Balance: $500

Withdrawal Amount: $200

Expected Remaining Balance: $300

## Technologies

- PHP

## How to Run

1. Install PHP.
2. Open a terminal in the project folder.
3. Run:

```bash
php -S localhost:8000
```

4. Open `http://localhost:8000` in your browser.
